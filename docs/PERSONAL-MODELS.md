# 新账号个人模型配置

上线时已有用户通过一次性迁移标记为 site，继续使用原站点 DeepSeek 环境变量；不会更新 users、sessions、user_memory 或助手记忆内容。新增 model_accounts 表记录账号的计费路由，个人密钥用 Fernet 加密并绑定用户ID。

新注册必须填写 model_name 和 api_key。目前仅支持 DeepSeek 官方地址 https://api.deepseek.com，模型需支持 JSON 输出与工具调用。注册进行格式验证，不发送付费探测请求；首次 AI 调用确认实际可用性。账号可在设置页更新自己的模型与密钥。旧账号登录不需要这些字段。

个人账号的训练解析、饮食分析、私教对话都只使用个人配置，不共享模型客户端缓存；错误、密钥缺失或密文损坏时不回退站点配置。官方食物查询、手动记录、本地OCR仍不需要模型调用。已有账号仍使用站点余额，因此本次功能并不把旧账号费用转移给用户。

密钥只由服务器解密调用，不写入聊天上下文、不回显到前端。加密主密钥文件为业务库同目录的 model-credentials.key，权限0600，由应用生成。备份脚本备份整个数据目录，会同时保存数据库和此文件，应当将备份作为敏感资料保护；掌握数据库与加密主密钥的人可以解密个人Key。文件丢失时不能通过重新生成恢复密文，必须恢复原文件。源码包不包含该目录。

PostgreSQL或Embedding配置不属于个人模型功能；当前部署没有开启额外Embedding服务。未来若启用，需要独立考虑其费用与数据传输。

回滚注意：恢复旧版程序会重新允许不带个人Key注册并重新走站点模型，不宜在有个人账号后直接回退到旧逻辑。旧业务数据备份仅用于故障恢复，不应覆盖上线后新增用户的数据。
