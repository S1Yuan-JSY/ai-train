# 自重训练与进阶

不依赖器械也能系统增肌与变强。自重训练的关键不是"动作多花哨"，而是**渐进超负荷**：不断让身体面对更难的自重变式。

## 基础动作库

- 上肢推：俯卧撑 → 上斜俯卧撑 → 标准俯卧撑 → 钻石/窄距俯卧撑 → 双杠臂屈伸（可用两椅）→ 倒立撑。
- 上肢拉：水平划船（桌下/床单下拉）→ 澳式引体 → 引体向上 → 负重引体。
- 下肢：自重深蹲 → 手枪深蹲/分腿蹲 → 保加利亚分腿蹲（背书包加重）→ 单腿罗马尼亚硬拉。
- 核心：平板支撑→侧桥→登山跑→悬垂举腿→龙旗（高阶）。
- 后链：臀桥→单腿臀桥→北欧挺身（腘绳肌，可退阶徒手）。

## 进阶逻辑（渐进超负荷的自重版）

1. 换更难变式（杠杆更长的动作）；
2. 加快向心/放慢离心（如 3 秒离心俯卧撑）；
3. 缩短组间休息或增加组数；
4. 负重：背包塞书、弹力带、负重背心；
5. 减小支撑面（窄距/单侧）。

## 新手自重周模板（每周 3 天，隔天练）

- A：深蹲 3×10、俯卧撑 3×6-10（斜板调到能做 6-10 次的角度）、水平划船 3×8、平板支撑 3×30 秒
- B：分腿蹲 3×8/腿、澳式引体 3×6-10、臀桥 3×12、侧桥 3×20 秒/侧
- C：同 A 或加 20-30 分钟快走/骑行

每个动作按"上次同组多 1-2 次"或"换更难变式"推进，6-8 周后考虑负重。

## 常见错误

- 只练俯卧撑和卷腹，忽略拉（背）与后链（臀腿后侧）——失衡会带来圆肩与腰痛；
- 动作代偿：俯卧撑塌腰、引体甩腿借力，宁可减次数保质量；
- 进步停滞时继续"每天 100 个"同一动作——缺少变式与负重是自重停滞主因。
